Every X/Y PAL release, newest first. Release notes between version 1.0 and 1.2.3 were not published on this site.

Version 2.0

New

  • New layout: a clearer performance view and a new edit view for portrait and landscape

  • OSC support: send to any host and port on your network, with your own address prefix

  • Instruments: set up your gear once as MIDI or OSC, and bind presets to it. Presets work on any device

  • Settings now have pages for Instruments, MIDI Outputs and OSC Targets

  • Synth library with named controls, so you choose CUTOFF, not CC 74

  • Hints on the pad that show what is missing and take you to the fix

  • Network MIDI switch for Macs on your network

Improved

  • More flexible slots: instrument and control, range, invert, return to minimum, name and color

  • Editing a factory preset makes a copy and keeps the original

  • Faster and safer sending: the touch screen never waits for MIDI or OSC

  • Your presets and settings from version 1 are migrated, and every route is kept

Version 1.2.3

Fixed

  • Bug fixes

Version 1.0

Released on 7 October 2019.

New

  • The first release of X/Y PAL: X/Y pads that send MIDI Control Change messages

  • Control up to 8 parameters per pad

  • For every parameter: set the MIDI channel and CC number, the CC value range, a name and a color, pick the MIDI output and invert the mapping

  • MIDI only. OSC came later
